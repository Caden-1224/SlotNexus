## 五节点 E2E 断言（fake_nodes_e2e_test）

- setup ×5：w-0..w-4 轮转路由到 echo/asr/rag/llm/tts 五个节点；
- echo {"text":"你好"} → "echo:你好"；
- asr {"text":"3"} → "第1帧(320) 第2帧(320) 第3帧(320)"；
- rag {"text":"VoxOrchestra 是什么"} → Top-2 JSON（k-voxorchestra 0.95 / k-arch 0.90）；
- llm {"text":"你好 世界 VoxOrchestra"} → "你好 世界 VoxOrchestra"；
- tts {"text":"VoxOrchestra"} → WAV 文件 684 字节（44 头 + 640 PCM），"RIFF" 魔数正确；
- 未知 work_id → not_exist；SIGTERM 七个进程全部退出码 0。
